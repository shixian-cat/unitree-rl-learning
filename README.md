# Unitree RL Learning Lab

A hands-on learning project for understanding reinforcement learning for legged-robot locomotion, using Unitree's official `unitree_rl_gym` as the reference implementation.

## Learning objective

Reproduce and explain the simulation workflow:

`Train → Play → Sim2Sim (MuJoCo)`

This project does not require a physical robot. Real-robot deployment is an optional later stage.

## Start here

1. Read [the study roadmap](docs/learning-roadmap.md).
2. For the first code reading session, follow the [official code map](docs/official-code-map.md).
3. Continue with the [PPO training loop lesson](docs/lesson-02-ppo-training-loop.md) and [baseline/evaluation lesson](docs/lesson-03-baseline-and-evaluation.md).
4. Read [the environment setup notes](docs/environment-setup.md) before renting a GPU server.
5. Follow [the official Unitree RL Gym repository](https://github.com/unitreerobotics/unitree_rl_gym) and its setup guide. Keep that upstream repository separate from this notes-and-experiments project.
6. Copy [the experiment template](experiments/templates/experiment.md) for every run.

## Recommended first target

Start with Go2 locomotion. First inspect a pretrained policy and its observation, action, reward, termination, and deployment configuration. Then run a short baseline training job, change one factor, compare results, and validate the exported policy in MuJoCo.

## Repository layout

- `docs/` — learning plan and setup guidance
- `experiments/` — experiment records and results
- `.vscode/` — workspace defaults

## Data note

For PPO locomotion, the primary training experience is generated by interacting with the simulator. Large general video datasets and physical-robot demonstrations are not prerequisites. See the roadmap for when demonstrations, real-robot data, and synthetic trajectories become useful.
